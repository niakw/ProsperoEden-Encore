This matrix is intentionally **NS1 + shared native platform**; the separate NS2 upstream optimization research owns NS2-specific changes. R02/R05/R17/R23 overlapping leads have a single owner here, not four copies.

**Classification (mutually exclusive):** `déjà intégré` (exact source/sha); `équivalent Encore` (behavioral test); `absent pertinent` (source gap, next proof); `non transposable` (architecture/platform); `à mesurer` (insufficient parity/performance evidence). “Source gap” does **not** mean a confirmed PS5 regression or FPS benefit. No positive behavioral test for these fresh commits was run.

### Additional guardrails

- The **155-commit Eden comparison** gave exactly **300 changed files** via the GitHub endpoint, which is a cap. This matrix selects *high-impact commits after the pin*, not a falsely complete source-by-source comparison.
- A later `main` commit may already resolve an item. The exact current gitlink and final **compiled** owner must be compared before proposing code.
- Legal: preserve upstream copyright/attribution by file, check licenses for models/assets separately, never redistribute games/keys/firmware.
- Evidence required for a candidate promotion: complete upstream commit(s), owner path and native compile/link selection, host positive/negative and O0/O2 sanitizer tests, no NS1 regression, native PS5 CI artifact and optional measured console A/B. `R22` static recompilation remains research only.

Second-pass source-level guard: [on-demand A/B source triage](../../tools/audit/check-ab-ns1-source-gaps.py), deliberately not wired to CI. See [qualification pass 2](ENCORE_AB_NS1_QUALIFICATION_PASS2_2026-11-10.md).
