# NS2 research: lawful homebrew validation without a Switch 2

Updated 2026-10-30. Scope: `research/ns2-ps5-compatibility` only. None of these
fixtures is a commercial game, a dump, firmware, title key or complete proof
of Switch 2 emulation on PlayStation 5.

**Important:** On Blockfall, SPIR-V is pre-existing Khronos Vulkan shader
bytecode; it is *not* the guest NVIDIA Ampere ISA generated by Switch 2 games.
A successful Vulkan dispatch does not validate Ampere SM86 capture, Maxwell
lowering, the HLE application manager, NSO/NPDM loading or PS5 RADV.

## Reproducible independent graphics test

Workflow: `.github/workflows/ns2-research-homebrew.yml` (two independent jobs: Blockfall Vulkan and HBLauncher native AArch64 ABI).
Commands on Ubuntu with `libvulkan-dev`, `spirv-tools` and Mesa:

```sh
python3 tools/check-ns2-homebrew-corpus.py --self-test
python3 tools/check-ns2-homebrew-corpus.py --output build-ns2-homebrew
g++ -std=c++20 -O2 -Wall -Wextra -Werror \
  tools/ns2/test_homebrew_vulkan_corpus.cpp \
  -o build-ns2-homebrew/vulkan-test -lvulkan
VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/lvp_icd.x86_64.json \
  build-ns2-homebrew/vulkan-test \
  build-ns2-homebrew/app.vert.spv \
  build-ns2-homebrew/app.frag.spv \
  build-ns2-homebrew/app.comp.spv
```

Validation thresholds:
1. **Acquisition:** every external input matches its original, fixed Git
   content SHA-1, length, SPIR-V magic, execution model and Vulkan 1.0 validator.
   Any mismatch fails closed. No outside code is executed by the downloader.
2. **GPU module:** actual `vkCreateShaderModule` for vertex, fragment and compute.
3. **Pipelines:** actual `vkCreateGraphicsPipelines` for vertex + fragment
   and `vkCreateComputePipelines` using ABI 1 storage buffer descriptor.
4. **Execution:** `vkCmdDispatch(1,1,1)`, fence wait, and a *readback assertion*
   that the Blockfall compute shader sets its game-initialized flag.
5. **Boundaries:** a software Vulkan/Mesa host test is not a PS5 GPU test;
   the fixture is never advertised as a Nintendo Switch 2 game or
   automatically injected into Encore's production shader cache.

The **HBLauncher CPU ABI** job retrieves only commit
`18b4748ba98eeac7df17beb5d3418985eb74897c`, builds and runs its
upstream host and QEMU AArch64 ABI tests. That verifies the source SDK
runtime and entry trampoline, not Encore's Dynarmic JIT, Nintendo HLE or PS5.
Its package format uses a custom `manifest.json` (`abi: 3`, `kind: native`)
and is not an NSO/NSP game.

Third-party artifacts are fetched into CI ephemeral directories and are not
committed, vendored, mirrored or attached to releases. The test implementation
and its provenance tool are independently authored under Encore's GPL license.

## Next actual-console qualification

Before declaring NS2 support: use an independently authorized native
NSO/ExeFS demo with auditable build/source, boot through Encore's NS2 loader,
record services/CPU instruction coverage, then verify display and input under
PS5 Vulkan/RADV, shader cache invalidation, save/reload and Switch 1
non-regression. A valid host SPIR-V corpus cannot replace these steps.
