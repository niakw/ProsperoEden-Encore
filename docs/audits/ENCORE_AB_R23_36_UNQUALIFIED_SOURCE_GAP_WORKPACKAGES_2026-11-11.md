## Mechanical exit contract for each case

1. **E1 source:** pin official upstream diff, exact *actually compiled* original/materialized/maintained source blob, active native headers, and the feature/guest ABI condition. Explicitly record overlaps with the eight already shipping backports and no-port choices. A textual upstream diff and a green inventory workflow alone are not implementation evidence.
2. **E2 host reproduction:** focused positive/negative tests and fuzz/sanitizer as appropriate (guest IPC buffer lengths/handles, parser bounds, JIT instruction golden vectors, SPIR-V caps/driver subgroups, GPU cache races/fences, controller callbacks), without accepting source-grep as an executable test.
3. **E3 native qualification:** selected PS5 compile commands, actual ELF/object symbols/headers, SDK and `RADV` graph, binary package/signature and console logs. A host runner failing DNS is infrastructure, not proof of a compiler defect.
4. **E4 hardware/guest:** cached and clean boot for at least representative NS1 title, relevant NS2 smoke on *shared* source changes, firmware 19/22/23 IPC where affected, live GPU color/depth/SGSR/framegen combinations, error/failure paths, and no regressions. A green CI alone is **not** E4.
5. **Release provenance:** R18 26 vendor families and archive hashes, 22 CPM tar source checks, remaining Boost byte mismatch, historical source 404 custody, current security advisories, SBOM/licences/notice and one distributable PS5 artifact. The specific remaining provenance issues are in the global master and R18 ledgers.

**Responsibility boundary:** PR #45 is audit evidence only; draft #46 carries isolated corrective work; #52 covers CPU6 ABI/launcher integration; #54 covers the narrower NS cmd23 alias; #55 covers AM/HID experiments. None of these is automatically assigned all the table's work or safe to merge from this document. Renderer R09 and NS2 special work are maintained in their distinct branches, with full combined-mode coverage required at integration.

**Exit verdict:** all generic upstream-source classification is now complete at E1, and **36 source gaps + hardware/dependency gates remain**. Do not describe the NS1/global *production audit and corrections* as complete until E2/E3/E4 and R18 closures have recorded evidence.
