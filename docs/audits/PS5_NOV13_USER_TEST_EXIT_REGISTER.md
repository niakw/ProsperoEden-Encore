**Log provenance correction.** The first 245 lines of `ns2/mkw/stderr.log` match `ns2/bananza/stderr.log` byte-for-byte as lines. They belong to the **same Bananza launch** (TitleID `040074A01BF12000`), with the `PC=4/LR=0` fault. The actual MKW segment starts later at `EDEN_PAD_MAPPING_CONTEXT title=0400c3f00006e000` and has its own NSO module sizes. Its `guest_run_begin` and `guest_frame_handoff=0` logs prove a loading stall, **not** a separate PC4. The previous issue/prose claiming an independent MKW PC4 was wrong; never count duplicated log prefixes as separate game executions.

The 27-image gallery count is **below** the obsolete 64-presentation cap. Thus that cap alone **cannot explain missing photos**. The tested binary scans only JPG/JPEG/PNG, not system HDR JXR, and only the fixed foreground-user gallery root. The source branch has later widened scanner bounds but cannot prove system album permissions or all physical paths.
