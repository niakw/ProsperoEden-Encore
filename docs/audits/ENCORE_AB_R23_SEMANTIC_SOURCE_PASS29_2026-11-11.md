## Two reviewed no-port decisions on the current PS5 target

**#6 — ARM64 NCE GPU page-fault preservation.** Upstream [`bfa72a22a345`](https://github.com/eden-emulator/mirror/commit/bfa72a22a345) repairs NCE-host CPU write faults interacting with pending GPU writes, via `NCEAccessFaultAction`, `TryInvalidateGPUMemory`, and optional `keep_tracking`. Real PS5 native is **x64 Dynarmic, not ARM64 host NCE**, and does not set `HAS_NCE`. The pinned `sources/eden/src/core/memory.cpp` blob **`837016de1d4efe74d2efb8df0d9de10aa10d8a26`** and `buffer_cache/word_manager.h` blob **`76d608bbe0dc375a496201daae4796aa4cd8e71c`** predate the NCE-specific contract. Newly optional `keep_tracking` is a caller-specific path, not proof the native x64 generic buffer tracker is wrong. **No NCE-port on PS5**; independently validate native CPU↔GPU coherency, dirty ranges and writeback under actual titles, alongside reviewed shipping GPU #94/#98.

**#111 — Dynarmic unified callback ABI and fence refactor.** Upstream [`9a30172e45fc`](https://github.com/eden-emulator/mirror/commit/9a30172e45fc) changes **25 files**, replaces per-size A32/A64 `MemoryRead8/16/32/64` and write callbacks with `MemoryRead(addr,size)` / `MemoryWrite`, updates x64 and ARM64 backends, test interfaces and removes some ordered `mfence`. PS5's maintained G11 x64 callbacks, optimized memory header and guest JIT wrappers remain on the current established ABI. This is an **unqualified performance/ABI migration, not a standalone bug fix**. No broad port. Reopen only on explicit measured Zen2 JIT win plus full memory-ordering, watchpoint, exclusive and NS1/NS2 ABI tests. Old per-width callbacks are not inherently missing guest semantics.
