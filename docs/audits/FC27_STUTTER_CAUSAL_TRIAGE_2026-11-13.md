# FC27 PS5 — causal stutter triage (13 November 2026)

## Status
**Regression/incident, no accepted performance improvement.** Do not merge optimizations as a replacement for the actual 13 Nov FC27 hardware re-test. Source builds, host synthetic tests and a nominal 30 FPS host-present counter are not performance evidence.

## Highest-confidence evidence already in the repository
- `docs/PS5_R350_2026-10-12_FC27_GPU_STUTTER_FORENSICS.md`: historical longer gameplay 28.37 mean present FPS, 1,035 present gaps >50ms, worst 574ms; 36 five-second windows with full guest→GPU command queue; late50-vs-full-queue wait Pearson 0.821; pipeline_configure 0.230, buffer+texture pair-held 0.184, guest CPU cache wait 0.160, JIT duration -0.018. This is **correlation**, not proof that the queue is the root cause. Producer queue wait total 2.179s across ~875s of samples; therefore queue sleeping directly cannot explain all present gaps.
- Same archival report: later frozen menu continued ~30 present FPS with almost no command queue pressure; `IHOSBinderDriver::TransactParcelAuto` waits were near the graphics-dequeue wall time (292.64s of 294.96s in the frozen-menu session). This points to producer/consumer buffer ownership, HLE progress and compositor wakeup **as a distinct mechanism**, not a defective FPS cap. The old logs predate newer wakeup patches.
- `docs/PS5_HOTPATH_FINDINGS_R441.md`: the Vulkan scheduler worker can wait for a first-use shader pipeline under `execution_mutex`; the guest-to-Vulkan translation and ordered creation remain capable of causing **cold-asset** stalls. No same-frame attribution proving this is the dominant sustained FC27 bottleneck.
- `docs/FC27_F07_MASTER_TRACKER.md`: known unresolved P0.1 guest shader translation, P0.2 pipeline waits, P1.1 guest JIT progress, P1.2 BufferQueue and presenter progression. A fast-first pipeline is a correctness trade-off; unbuilt/incorrect shader fallback cannot be accepted to improve a counter.
- `docs/PS5_RESOURCE_RECLAIM_AND_GPU_CPU_SCALE_DESIGN.md`: worker CPU affinity, shader compiler population and synchronous native heap growth may increase contention. Do not increase threads/cache size without confirmed native per-frame evidence. Source-only optimizations are not proof of gain.
- The Nov 13 user report includes newly broken FC27 faces/hair/limbs/kits/text HUD and game menus, and no improvement with Mihawk. These are visual fidelity/guest progression regressions, **not** explained by the 30 FPS limit or frame synthesis.

## Investigate in this order
1. **Preserve pixel correctness first.** Reproduce same title and scene against last known visually better PS5 binary. Compare selected renderer source/feature flags, async shader fallback (especially missing vertex/mesh components), SPIR-V varyings, texture pool alias/eviction, descriptor residency, GPU-written dirty image transitions and actual frame/HUD freshness. No blanket cache purge, disabled barriers or unbuilt shaders.
2. **Separate two stutter classes.** Match-start cold-content burst: guest shader translation, first-use pipeline-ready wait, game-to-GPU queue fullness and GPU worker activity. Sustained/frame-pacing: BufferQueue `DequeueBuffer` wait, `HardwareComposer::ComposeLocked` wait/release order, producer wakeup and visible-frame progression. Treat guest pause/menu freeze as separate until proven common.
3. **Attribute per-frame wall time**, not aggregate multi-thread milliseconds. Pair `EDEN_VULKAN_FRAME`, `EDEN_FRAME_PRESSURE`, `EDEN_DEV_GPU`, `EDEN_DEV_HLE`, `EDEN_GPU_CACHE_PHASE`, shader subphase and command producer IDs. Existing parsers: `tools/analyze-fc27-stutter.py`, `tools/analyze-fc27-release-sessions.py`, `tools/analyze-ps5-frame-windows.py`. Normal release-mode fields absent must be marked **unknown**, not zero.
4. **One-variable A/B** at identical FC27 match, 1440p/1x, same game revision and initial cache state, diagnostics OFF except bounded capture. Compare old visually better binary and new candidate with same native firmware, ROM/updates and game settings. Require improved late50/100, worst gap, unchanged FPS progression, accurate player/HUD pixels, audio/video startup, input and clean exit.
5. **Separate Mihawk acceptance**: game/source FPS (simulation) vs presented/generated FPS and latency; no claim of 60 simulated FPS from a 30 FPS-cap source, and never interpolate repeated images from a stalled guest.

## Safety and release decision
FC27 remains **not accepted** until a console scene-aligned A/B establishes both correct image and improved frame-time distribution without new teardown crashes. NS2 shared-memory initialization crash is a separate root-cause candidate addressed in vendor PR #97; host compilation does not demonstrate console compatibility.
The active working branch must remain isolated; do not reset, broaden or merge the source until the vendor pointer, all host checks and native package have been validated. `tools/check-nov13-ps5-crash-ui-regressions.py` checks source contracts, not real PS5 FPS.
