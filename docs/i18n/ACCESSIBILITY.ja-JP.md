大きい文字、高コントラスト、動きの軽減はアクセシビリティ設定で個別に有効にできます。初期状態はすべてオフです。ランチャーで操作できることは、すべてのゲームのアクセシビリティを保証しません。

## 設定 · Touchpad

ゲーム中に Touchpad を短く押すと Encore のクイック設定を開けます。中央のシステムボタンは本体専用で、このメニューには使用しません。グラフィック、ボタン割り当て、FPS、診断情報を確認できます。変更内容によってはゲームの再起動が必要です。言語は Settings → Language で選択できます。メニューにはPS5の公式システム言語31項目のみが表示されます。

`L1/R1` · `Settings → Accessibility` · `Settings → Controls`

## 設定

推奨初期設定は Vulkan、テレビ出力 1440p、ゲーム内部倍率 1.25x、空間アップスケーリング FSR 1（シャープネス 50%）、FXAA、60 Hz です。テレビへの出力解像度とゲーム内部解像度は別です。フレーム生成はゲームの処理速度そのものを上げません。

## サポート

GitHub Issues には Encore のバージョン、PS5 ファームウェア、再現手順、関連する設定、個人情報を取り除いたログを記載してください。鍵、セーブデータ、個人情報は公開しないでください。

/data/prosperoeden/ を削除しないでください。設定、セーブデータ、鍵が保存されている可能性があります。外部ストレージもバックアップしてください。
