# Prospero.Eden Encore — Installation (English UK)

[All 31 PS5 language choices](../../LANGUAGES.md) · [English US complete reference](../../INSTALL.md) · [PS5 language policy](../PS5_SYSTEM_LANGUAGE_POLICY.md)

Start from an official, complete, release-qualified package; read the specific SHA and tested firmware. Firmware 13.60 is the only console-tested target, not advice to update. Back up the complete `/data/homebrew/PPSA99008/`, `/data/prosperoeden/` and external storage roots before upgrading; the second root contains user-owned data and may include saved games.

Follow the complete ZIP/FTP or FFPFSC installation procedure. Install the full application folder, not only `eboot.bin`: all 31 `ui/lang/*.po` catalogues, including distinct en-GB and en-US, belong in the package. If the language or graphics setting fails, use documented reversible recovery instead of deleting saves or user-supplied keys and firmware.
