# Eden Encore — functional PS5/NS2 upstream comparison (19 November 2026)

**Scope:** engine `niakw/ProsperoEden-Encore` plus pinned vendor `niakw/Prospero.Eden-Encore-vendor`. This is a code/provenance and reported-console-evidence audit, **not a new PS5 execution**.

**Reference heads inspected:** Encore engine `5368970e` (after the quiet-boundary host check, ahead of this audit), vendor `8153654a2f1f`; [heydemoura/EglantinePS5 `c059f77e`](https://github.com/heydemoura/EglantinePS5/commit/c059f77e213ba1f4fb3ef4151253c5715cd52cc4) (19 Nov); [viejunerd/Eglantine-PS5-](https://github.com/viejunerd/Eglantine-PS5-) (documented base PS5 firmware **13.60**, independent fork); [Eglantine #350](https://github.com/Eglantine-Community/Eglantine/issues/350); Lichii `nx2`. Current hardware evidence is the Encore [R457 console archive audit](PS5_R457_2026-11-19_FC27_NS2_LAST_SESSION.md), engine `2b0975f7`, vendor `9a83a6ba`. Do not substitute a newer source commit for that console binary.

## What genuinely works upstream (with qualifications)

- [EglantinePS5 PR #125](https://github.com/heydemoura/EglantinePS5/pull/125): on **PS5 Pro**, Mario Kart World entered a race and ran ~392 s before a distinct host guest-memory fault under pressure. The change reuses shader IR pools, zstd probe state and starts descriptor queues smaller. It reduced total allocation *traffic* by ~4.7 GB **without demonstrating a net resident-memory reduction**; do not report a memory leak fixed.
- [PR #102](https://github.com/heydemoura/EglantinePS5/pull/102): **PS5 hardware-confirmed** Bananza first-wall `VK_ERROR_DEVICE_LOST` from ~26,738 copies / ~53,477 barriers in one AGC submission. A bound of 8,192 copy regions per submission got 3/3 runs through the wall. This is a gameplay fix **after initial boot**, not Encore's early `PC=4` root cause.
- [PR #104](https://github.com/heydemoura/EglantinePS5/pull/104): PS5-oriented 64 Ki A64 fast-dispatch table and sparse GPU page entries; measured combined ~250 MiB in-use reduction on Zelda on PS5 Pro, different scene and core. The PR explicitly says main integration was not itself rerun on console. No isolated per-component speed claim.
- [PR #128](https://github.com/heydemoura/EglantinePS5/pull/128): 29 upstream improvements/backports; their owner documents PS5 Zelda A/B gameplay success, but much of the 29-change set is new and not isolated to one patch. Inspect dependency trees before importing.
- [PR #127](https://github.com/heydemoura/EglantinePS5/pull/127): Fire Emblem second native DLSS prepass recognition, PS5 GPU-fault elimination in the reported title; *title-specific* shader key, not evidence of a generic MKW/Bananza boot correction.
- [viejunerd Eglantine-PS5 README](https://github.com/viejunerd/Eglantine-PS5-/blob/main/README.md): firmware **13.60**, Bananza `.nup` reports gameplay (10–25 fps by zone); MKW is reported reaching a race on some builds but also OOM / GPU stalls. Their Switch 2 defaults emphasize faster GPU emulation and non-reactive flushing, which differ from Encore's generic current tiers. This is **not** an A/B against Encore on the same game image.

## Prioritized next engineering work

1. **Finish source CI and qualifying the exact engine/vendor pair**, including newly added quiet receipts. Build one PS5 package only when source preflight is fully green; audit link/SELF, symbols, artifact and SHA.
2. Reconcile the first instructions of MKW/Bananza: loaded main/NPDM/patch provenance, guest context and stack mapping, last successful SVC and first null return. The shared `PC=4` is a signature, **not** proof that larger stacks or an imported buffer-copy patch will boot either game.
3. Candidate upstream backports in **isolated scoped commits**: PS5 long-copy submission limit (#102); A64 dispatch/page-state footprint (#104); shader-pool/zstd reuse (#125). Native source/ABI and host tests first, console validation next. Do not flip global reactive flushing or task/mesh behavior without the game-generation-specific correctness review.
4. When a qualified boot reaches gameplay, test NS2 GPU Ampere render + memory/resource stress, audio/video, exit/relaunch and FC27's cold/warm 5-second windows. Keep `#123` (NS2 PC fault), `#100` (FC27) and `#281` (relaunch) open until runtime exit criteria are met.

**Unverified:** no new MKW/Bananza launch on Encore from these commits, no native PS5 build, no PS5 benchmark of candidate optimizations. Comparing two different consoles, drivers and game update containers cannot establish direct causality.
