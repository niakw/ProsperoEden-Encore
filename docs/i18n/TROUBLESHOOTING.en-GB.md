# Prospero.Eden Encore — Troubleshooting (English UK)

[All 31 PS5 language choices](../../LANGUAGES.md) · [English US complete reference](../../TROUBLESHOOTING.md) · [PS5 language policy](../PS5_SYSTEM_LANGUAGE_POLICY.md)

Green source/host checks do not establish on-console compatibility. Firmware 13.60 is the only confirmed device target; no NS2 game has been confirmed to render its first guest frame on PS5. Identify the complete release SHA, content format, renderer and reproducible steps when reporting a fault.

Check storage roots and actual files if a title is missing. Use Safe Launch or documented resets instead of deleting `/data/prosperoeden/`, which may contain personal saves, settings, firmware and keys. The Multiplayer browser listing alone is not guest LDN support; from the in-game touchpad overlay it is opened only after closing the current game, so preserve unsaved progress first.
