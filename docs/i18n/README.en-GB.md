# Prospero.Eden Encore — Overview (English UK)

[All 31 PS5 language choices](../../LANGUAGES.md) · [English US complete reference](../../README.md) · [PS5 language policy](../PS5_SYSTEM_LANGUAGE_POLICY.md)

Prospero.Eden Encore is an experimental Nintendo Switch 1 and Switch 2 emulator fork for PS5, with firmware 13.60 as the only console-tested target. It offers a DualSense TV-first launcher, per-game video profiles, artwork, graphics settings, safety controls and diagnostics. Experimental NS2 code is not a verified promise of Switch 2 gameplay on the PS5.

Customise the colour theme and controller mappings in the launcher. In Vulkan games, the touchpad quick overlay includes a Multiplayer shortcut, but confirming it **closes the running game** before opening the launcher lobby. This is not a live in-game room browser, and successful guest networking is not yet device-qualified.
