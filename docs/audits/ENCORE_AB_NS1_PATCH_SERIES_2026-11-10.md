## P0 AudioIn code changes and limitations

`NullSinkStreamImpl::ReleaseBuffer` returns an empty vector for every nonzero AudioIn request. The pinned `audio_core/device/device_session.cpp` subsequently copies `buffer.size` bytes from `ReleaseBuffer(buffer.size / sizeof(s16)).data()`. Returning a correctly sized silent vector closes the **nonzero-even-length null-buffer** hazard on this adapter; it does not fix the original DeviceSession's lack of explicit odd-byte alignment validation, invalid guest address checks or arbitrary huge buffer allocation. These are separate required pre-release tests and possibly a separate maintained device-session owner change. **Do not claim memory-safety signoff merely from the helper test.**

This branch's host-only tests compile `tests/ab_ns1_audioin_silence_host.cpp` using Clang C++20 and ASan/UBSan and check the actual source wiring. The `headless/devices_check.cpp` native fixture further tests the real `AudioSink` input-stream object, but requires a supported native/devices check build to execute; host helper tests alone cannot run that PS5-specific unit.

## Merge and synchronization protocol

1. Keep both PRs **draft** until each test gate is demonstrably green at a frozen SHA. A research-only audit PR is not merged with corrective code; only specific proven source changes graduate.
2. Main may advance independently during P5. Before proposing a production merge, compare latest `main`, native build SHA, gitlink and SDK headers. **Do not repin vendor or alter build workflows while a main PS5 build is being qualified.**
3. Apply vendor-needed batches through an **independent pinned vendor change/review** only once authorized, then record the exact single vendor gitlink bump in Encore. Never overwrite `vendor/sources` to hide the 35-file discrepancy.
4. A green sanitizer helper, source static check or CMake graph is **not** proof of linked ELF or 30/60 FPS gameplay. A full device validation is a separate P5 acceptance step.
5. If an individual batch fails a guard, revert that one commit and preserve the other batches. No wholesale Eden/Mesa update.
